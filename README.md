# 💧 Simulador de Economia de Água

## Descrição

O Simulador de Economia de Água é um projeto educativo desenvolvido para conscientizar sobre o uso responsável dos recursos hídricos. A aplicação permite calcular a economia de água obtida com a adoção de práticas sustentáveis, mostrando o impacto positivo dessas ações ao longo do tempo.

---

## Objetivo do Projeto

Demonstrar a importância da conservação da água e incentivar hábitos sustentáveis por meio de uma ferramenta interativa e educativa.

---

- CSS3

- GitHub Pages

## Funcionalidades

✅ Simulação de consumo de água

✅ Cálculo de economia mensal

✅ Cálculo de economia anual

✅ Classificação de sustentabilidade

✅ Interface responsiva

✅ Educação ambiental

---

## Como Executar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html`.
3. Informe o consumo mensal.
4. Escolha uma prática sustentável.
5. Clique em "Calcular Economia".

---

## Relação com o Tema Agrinho

### Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente

O projeto demonstra como pequenas ações podem contribuir para a preservação dos recursos hídricos, fortalecendo a sustentabilidade no campo e garantindo água para as futuras gerações.
